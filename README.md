# Property Price Predictor (rebuilt from the supplied CSV)

## Files
- `train_model.py`: trains a CatBoost regression model from the dataset.
- `app.py`: serves the standalone prediction website and optional JSON API.
- `bproperty_data_cleaned.csv`: your cleaned dataset (add this file to the repository).
- `property_price_model.cbm` and `model_metadata.json`: generated by training.

## 1. Train locally
Use Python 3.10–3.12 recommended. In this folder, put `bproperty_data_cleaned.csv`, then run:

```bash
python -m pip install -r requirements.txt
python train_model.py --data bproperty_data_cleaned.csv
```

Training produces `property_price_model.cbm`, `model_metadata.json`, and `model_metrics.json`.
Do not use the old model file unless it was trained with the same feature columns and target transform.

## 2. Run locally
```bash
uvicorn app:app --reload
```
Open `http://127.0.0.1:8000`. Health check: `http://127.0.0.1:8000/health`.

## 3. Deploy to Render
Commit and push these files to GitHub:
- `app.py`
- `train_model.py`
- `requirements.txt`
- `render.yaml`
- `bproperty_data_cleaned.csv`
- generated `property_price_model.cbm`
- generated `model_metadata.json`

Render's start command is:
`uvicorn app:app --host 0.0.0.0 --port $PORT`

The service does not automatically retrain on every deploy. Train locally when the dataset/model changes, then push the newly generated model and metadata files.

## Important limitations
The dataset is listing/asking prices, not verified sale prices. Evaluation metrics are in `model_metrics.json` after training. It includes 2,856 apartments, 197 plots, 22 buildings and 10 duplex listings; predictions for rare property types may be unreliable. Avoid presenting outputs as guaranteed market values.
